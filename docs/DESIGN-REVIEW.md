# Design correction 0.0.3
The real 0.0.2 screenshot exposed crowding, missing visual hierarchy, a tiny window and first-run menu hint. This pass uses native widget layout spacing/alignment, direct and child stylesheet selectors, larger numbers and metadata, full-window Player and a separate Browse workspace. No virtual mixer. Native library remains reachable via Browse. The new screenshot is required before calling this design complete. No hardware or runtime layout verification yet. References: https://github.com/mixxxdj/mixxx/wiki/Creating-Skins and https://github.com/mixxxdj/mixxx/wiki/Widget-Alignment .
