# Inventário de assets

O pacote de arquivo separado contém os originais binários recuperados da conversa; a API de escrita do GitHub usada nesta sessão não recebe ficheiros binários diretamente. Não fingir que os binários já estão na main. Depois de extrair o ZIP, copiar assets/images e assets/manuals para o repositório se desejado.

- assets/3d/ns6-studio.html — HTML original recuperado.
- assets/controller/ — XML e JS do mapping original, preservados por Git blob.
- assets/manuals/ — Numark NS6 ITCH Reference Manual v1.01 e QSG; páginas de referência em PNG.
- assets/images/concepts/ — imagens geradas Apple/AlphaTheta, variantes, renders da controladora e referências.
- assets/images/3d/ — previews do NS6 Lab.
- assets/images/history/ — screenshot real rejeitado, não conceito de design.
- research/ — relatório de viabilidade e fontes.
- assets/manifest-sha256.json — inventário de integridade no pacote local.

Não redistribuir publicamente manuais, fontes ou mapping sem verificar direitos. Repositório privado.
