# NS6 Lab — interactive 3D reference
Open [ns6-studio.html](ns6-studio.html) locally in a WebGL-capable browser. Self-contained procedural geometry, no imported CAD model; CPU fallback exists in source. Drag to orbit/zoom, select and manipulate controls, top/rear cameras, reset and inspector. Two physical decks with layer simulation, four mixer channels, jogs/knobs/faders/hot cues/transport/loops/FX and simplified ports, procedural face textures. Includes learning drills from earlier separate project; no physical device connection, WebMIDI or real audio mixing. Values/BPM/LED states simulated. Geometry is not calibrated manufacturing data. Preserve as reference, not part of Performance runtime. Screenshots are in the archive's assets/images/3d folder.
