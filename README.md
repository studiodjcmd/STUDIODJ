# Studio DJ — arquivo do projeto

**Estado: investigação e design; implementação suspensa.** Um ambiente DJ local de alto desempenho, inspirado na ergonomia AlphaTheta/CDJ e na linguagem visual Apple, para a Numark NS6 ORIGINAL de quatro decks. Não é um produto pronto nem uma skin recomendada para utilização.
